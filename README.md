# 🌐 Projeto Social

Projeto desenvolvido para apresentar minhas redes sociais
de forma visual e interativa.

## ✨ Sobre o projeto

O projeto permite que as pessoas conheçam e acessem minhas
redes sociais através de uma interface visual, com foco no
design e nas interações da página.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎨 O que pratiquei

- Estruturação de páginas com HTML
- Estilização com CSS
- Organização de imagens e arquivos
- Criação de uma interface visual
- Interações entre elementos da página
- Publicação do projeto na web
